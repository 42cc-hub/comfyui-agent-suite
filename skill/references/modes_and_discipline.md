# 两种工作模式：**半自动（默认）** 与 自动（需明确授权）

**默认判据：用户说要什么，就只做什么。** 没被要求就连跑多轮、自己改提示词/参数、
自己判定"这张没问题"，都不属于被要求的事 —— 而 agent 本身又看不出图坏在哪，
自作主张的代价（白跑的 GPU、用户回头收拾）由使用方承担。

## 0. 一句话判据

**用户没说的动作 = 不做。** 不确定就停、就问、就交给人看。
**"我觉得没问题"不是验收结论。**

## 1. 半自动模式（默认，不需要用户声明）

| # | 规矩 | 反例 |
|---|---|---|
| 1 | **只做被点名的事**：不加步骤、不换模型/参数/提示词、不"顺手优化"、不在未被要求时连续跑多轮（一轮 = 用户交代的一件事，做完就交付） | 用户说"出一张看构图"，agent 自己出 6 张、自己挑参数、自己改提示词 |
| 2 | **不擅自重试**：结果差或报错，先报事实 + 一句诊断，等指令 | 检测器报了 3 个可疑部位，agent 自己重绘两轮再说 |
| 3 | **判不了就停**：图对不对、像不像、能不能交付 —— 这些交给人眼（面板对比卡 / `human_canvas` / `ps_edit`），不要自己下结论 | agent 声称"手已经修好了"，用户一眼看出还是坏的 |
| 4 | **步进可见**：每一步的产物先给人看（**一次面板调用**），再做下一步 | 一路跑到交付才把图贴出来 |
| 5 | **只动被点名的地方**：写权限边界见 §3；`output\` 永不碰 | 把中间产物写进 `output\` 或覆盖用户的文件 |
| 6 | **贵 / 慢 / 不可逆的动作先报后做**：云 API（花钱）、批量、训练、覆盖、删除 | 直接调云端编辑器改了 8 张 |
| 7 | **报事实，不报感觉**：路径、seed、尺寸、耗时、检测器输出、差异百分比 | "应该没问题""看起来不错" |
| 8 | **不假装看过图**：没跑 WD14 gate 就不 `read_image`；没看图就不能评论画面 | 没读图却描述画面内容 |

## 2. 自动模式（**只有用户明确授权后**）

* 触发：用户说"**你来定 / 自行决定 / 随便做 / 不用问我**"——**一次授权只管这件事**，下一件事回到半自动；
* 允许：自主选参数、多轮迭代 + 自检、批量重试、自己挑最终稿；
* **仍然不许**：碰 `output\` 等用户目录、不报就花钱、把没过 gate 的图读进上下文、改用户的既有文件。

## 3. agent 的默认写权限边界（与 SKILL.md 的 Cleanup 硬规则一致）

* **可写**：本次任务自己的工作区 / task 目录（默认 ephemeral；要留就**显式** promote 到 task 目录）；
* **只读**：`models\`（除按规范新增）、`input\`（除既定的 `input\dsh_edit\` 交换目录）；
* **NEVER TOUCH**：`<你的 ComfyUI 安装目录>\output\`（混合目录：用户文件与历史产物混放，只能按文件名逐个处理）；
* 生产图**只进 `temp\`**（随重启清空），要留的**显式转存**并写进交付步骤（见 SKILL.md 的 Cleanup 节）。

## 4. "agent 看不出图坏"怎么办：**客观自检 + 交给人眼**

**能自动查的（必须先跑，别用猜的）**：

| 问题 | 工具 |
|---|---|
| 这张图能不能进我的上下文 | `libs/wd14-gate/scripts/wd14_gate.py`（BLOCK 就只给路径；要自己看则先打码：`scripts/tools/mosaic_censor.py`，全自动无人工时用 `scripts/tools/pose_censor.py`，**放行判据**用 `scripts/tools/gate_after_censor.py`：关键点词汇消失即放行、有残留即不放行） |
| 尺寸 / 亮度 / 是不是全黑全白 | 一行 PIL/numpy 统计，**报数字** |
| 人 / 手 / 脚 / 指趾 / 口塞 / 眼罩 / 掩版 | `scripts/check_parts.py`（套件检测器，出 JSON + flags） |
| 重绘有没有渗出掩版 | `diff_report.py base out --mask m` → 看 **8/255** 那一档 |
| 抠图好坏 | `compare_matte.py` / `score_matte.py`（对 GT 打分） |
| 两版哪个更好 | 同框对比卡（`dsh_show_media compare_with`）**交给人判** |

**不能自动查的（必须交给人，不许自己结案）**：构图好不好、像不像那个角色、手有没有画错但检测器没报、
表情/氛围对不对、这份交付能不能发。

**两条硬要求**：
1. 自检结果**要么给数字、要么说明"这一项自检覆盖不了"**；
2. 自检通过 ≠ 交付通过 —— 交付前的那一眼**只有人能下**。

## 5. 半自动模式下的交付话术（模板）

> 做完了 X。产物：`<路径>`。参数：seed `<n>` / 尺寸 `<WxH>` / 模型 `<name>`。
> 自检：Y 通过、Z 报警（数字：…）。**要不要我做下一步 W？**

——不要写"已经优化好了""应该没问题""完美"。
