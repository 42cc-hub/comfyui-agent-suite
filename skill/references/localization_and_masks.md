# 定位与掩版：四条路，先选路再动手

"这块要重绘/要打码，掩版从哪来？" —— 有四条路，**代价与可靠性差别很大**。先按这张表选一条，
别默认用最贵或最省的那条。

| # | 路子 | 机制 | 代价 | 可靠性 | 什么时候用 |
|---|---|---|---|---|---|
| 1 | **检测框** | 本机 `libs/anime-detection`（人/头/手/脚 + 面部四类）给框 → 由框推掩版 | 免费、本机、几秒 | **高**（头框尤其准） | 默认首选：单人或**分得开**的多人、部件重绘（手/脚/脸/眼/嘴） |
| 2 | **视觉模型分色** | 把图 + 提示词交给云端图像模型（如 DashScope `wan2.7-image`）："A 涂红、B 涂蓝、背景涂黑" → 阈值转掩版 | **要钱**（按次计费）、~10 秒、要联网 | **高** —— 用户评价"**直逼人 PS 画出来的质量**"；语义身份最清楚，边界干净。**抠图口径实测比 SAM 干净 8 倍**（空洞面积 3.5k vs 29.2k px） | 两人**贴在一起/互相遮挡**、要按"是谁"分；**抠图/去背景**（见 `matting_and_cutout.md` 路线一B）；也当**身份判据** |

> **用途决定要不要为它花钱**（用户 2026-10-12 提的口径）：
> **重绘**时其实**不需要这么高的精度** —— 姿势微调、加物件这类改动要的是**比目标更大的空间**
> （轮廓 + 外扩），掩版略大反而更好用（`mask_from_colors.py --grow 8~20`）。
> ⇒ 重绘时先看路 1（免费）；只有"**分不清是谁**"或"**被遮挡**"才为了**语义正确**花这份钱。
> **抠图**时正相反：精度直接决定成品，而这条路实测**比 SAM 干净一个数量级**（不漏发缝），值得花钱。

**价格与省钱开关**（官方价，2026-10-12 查自 [wan2.7-image 模型页](https://www.alibabacloud.com/help/zh/model-studio/wan2-7-image)）：

| 模式 | 官方价 | 一次掩码约合 | 实测质量（同图抠图口径） |

| **`prompt_extend=false`（本工具现在的默认）** | **$0.01434/张** | **¥0.10** | 空洞 5,373 px（76 块），与上面 IoU **0.95** |

- 区域价不同：华北2/东京 $0.027504、新加坡 $0.03（每张，与原图尺寸无关）。
- **掩版/分色/纯黑白抠图这类指令本来就不该被改写**（改写会把"涂纯红/纯黑"改成它自己的一套描述），
  所以关改写是**又便宜又听话**：`bailian_image_edit.py` 现在默认 `prompt_extend=false`，
  要旧行为加 `--prompt-extend`。
- 量级感受：100 张图各来一张掩版 ≈ **¥10**（关改写）；一张插画通常 1~3 张掩版 ⇒ **¥0.1~0.3**。
| 3 | **网格 + 坐标估计** | 叠加网格（`tools/crop_view.py --grid`）或 ASCII 图（`tools/ascii_map.py`），人/agent 估坐标 | 免费 | 中（人是估的） | 沟通"哪一块"、粗裁切、给上面任何一条路做前置定位 |
| 4 | **画布让人涂** | `human_canvas`：人涂多层（要改的/要保留的）+ 矢量点 | **要人**、非阻塞（打开 → 让出回合 → 读回） | **最高** | 前三条互相矛盾、边界是"判断"而非"测量"、或者错了代价很大 |

## 决策顺序（省时间版）

1. **先跑检测**（路 1）：单人、分得开的多人、部件级重绘，它基本够用，而且免费。
   - 头 → **头框的内接椭圆**（`check_parts.py --person-masks` 已这么做）；
   - 手/脚/脸/眼/嘴/口塞/眼罩 → `check_parts.py --feature-masks` 直接给框。
2. **多人贴在一起时**，检测仍准（实测：两个 head 框的 `person_id` 与我裁图目视判断完全一致），
   但"**检测框 ↔ 骨架链**"的配对会出错（实测出现某个 person 框因 `no_skeleton` 被丢弃）。
   - 立刻可用的修法：`check_parts.py --person-masks --allow-box-only-persons --no-merge-overlap --person-mask-cover skeleton`
     —— 会把没骨架的人也保留、且不再把两人合并；**代价是可能出多于两人的掩版**（本例 3 块），需要你裁掉多余的。
   - 想确认"哪块是谁" → 用**路 2** 或**路 4**。
3. **要按语义分人**（"棕发那位""站左边那位"）→ 走**路 2**：模型直接回答"谁是谁"；
   实测它能在膝枕这种遮挡关系下给出干净的两块（红∩蓝 = 0 px）。
4. **路 2 与路 1 不一致，或者边界本身就是判断**（一缕头发算谁的、道具算不算在身上）→ 走**路 4**，把画布交给人。
   这是最稳的一档：人给的是"判定"，比任何模型都硬。

## 路 2 的具体做法（实测过的提示词）

```bash
# 1) 云端分色（示例：棕发女孩红、白发女孩蓝、沙发黄、其余黑）
python scripts/bailian_image_edit.py edit IN.png colorblock.png \
  "把图中棕发双马尾女孩的像素全部涂成纯红色 #FF0000；把白发（带蓝色挑染）女孩的像素全部涂成纯蓝色 #0000FF；
   把沙发涂成纯黄色 #FFFF00；其余背景与家具全部涂成纯黑色 #000000。
   输出一张纯色块分割图：不要保留细节、不要阴影、不要渐变、不要文字。" \
  --model wan2.7-image

# 2) 分色 → 掩版（灰度 + 可直接喂 ComfyUI 的 RGBA）+ 质检
python scripts/tools/mask_from_colors.py colorblock.png --out-dir out/masks \
  --rgba-base IN.png --colors "red=#FF0000,blue=#0000FF,yellow=#FFFF00" --preview \
  --check-boxes out/parts/IN.json          # 数碎片 + 核对每色落在哪个 person 框里
```

**实测数字**（2026-10-12，膝枕双人图，1024×1536）：

| 指标 | 值 |
|---|---|
| 耗时 / 价格 | 8.1 秒（`wan2.7-image`，200 OK）；**按次计费，不免费** |
| 输出 | 1672×2508（模型放大了；**必须用最近邻缩回原尺寸**） |
| 纯色纯度 | 99% 像素落在四种颜色 ±60 内（1.9% 是边缘抗锯齿） |
| **碎片** | 蓝 = **1 个连通块**；红 = 4 个但主体占该色 **100%** ⇒ **零碎片、零杂块** |
| 红 ∩ 蓝 | **0 px**（两人不重叠） |
| 框内占比 | 红 81% 落在 pid1（胡桃）框内；蓝 93% 落在 pid0（芙宁娜）框内 |
| 与检测掩版 | 红覆盖检测#0 的 75%、其中 66% 落在它内 ⇒ **互补**（Wan 更全，含长发/被挡部分；检测掩版更紧） |
| 边界 | 各自 1px 边界环带约 76% 落在检测掩版并集附近 ⇒ 走向与人体轮廓一致 |

⇒ **结论**：**质量接近人工绘制的掩版**（无碎片、不重叠、语义身份明确），代价是**要花钱**。
建议这样用：
- **难姿态（两人接触/遮挡）默认走它** —— 比在检测掩版上做人工补救省得多；
- 简单单人/分得开的多人仍先用**路 1**（免费）；
- 边界仍是"生成"的：做**几个像素级**的极小区域重绘时，把它的掩版与检测掩版**求交**后再用（或改走画布）；
- **颜色不要和画面本身撞**（红绳/红底就别用红，改品红 #FF00FF），并在提示词里把"不要渐变/不要细节"说死。

## 路 4（画布）的用法

```python
human_canvas(action='open', image=IMG, task='mask', seed_json={'layers':[{'name':'要改的','label':'foreground','color':'#ff5050'},{'name':'要保留','label':'keep','color':'#5050ff'}]})
# 打开后**让出回合**，等人回话；再 human_canvas(action='status', task=...) 读回图层
```
图层读回后用 `scripts/tools/canvas_mask.py --paint L1 --keep L2 --src IMG --out mask.png` 合成
（`L1 − L2`，可选 `--dilate/--feather`）。人在缩略图上涂时，记得把 `--dilate/--feather` 按缩放比例换算回原尺寸。

## 不管走哪条路，交付前都要做的三件核对

1. **叠加图核对**：`scripts/tools/mask_overlay.py BASE.png MASKS_DIR --out check.png`
   —— 打印每块的像素外接框，并出叠图。**多人强重叠时掩版的编号/JSON 的 person_id 都可能与直觉相反**
   （实测踩过：掩版喂反 ⇒ 用"闭眼睡觉"的提示词重绘了另一个人的脸，眼睛颜色当场串味）。
2. **不重叠**：两块人掩版必须 0 px 重叠（`check_parts.py --person-masks` 的默认行为；
   分色法则靠阈值本身互斥）。
3. **哨兵验证**：重绘**A** 之后，**B** 的特征不该变 —— 挑一个醒目的哨兵（本例用"胡桃的眼睛是红的"）逐遍检查。
   掩版干净时 `SetLatentNoiseMask` 不会污染掩版外；**不要用"贴回"（ImageCompositeMasked 之类）去补救，那一定会出边缘问题**。
