# 生产流程主线：先画什么 → 什么时候编辑 → 什么时候放大

这是**宏观层**的唯一出处：一张图（单人也适用）从立项到交付的 6 个阶段、每个阶段的**入口判据 / 出口判据 /
常见返工点**。细节参数仍在各自专题文档里（本文件每步给出指向）。

## 一条主线（照抄）
| # | 阶段 | 干什么 | 判据（出口） |
|---|---|---|---|
| 1 | **抽卡定底图** | **Anima**，**小尺寸（`800×1200` 挡位）** 跑 **3–5 张**，挑结构对的 | 人数 / 关系 / 姿势 / 机位 / 遮挡全对；不对就**继续抽**，别往下走 |
| 2 | **大尺度结构性修正** | 胳膊腿位置、身体朝向、谁在哪儿 —— **人工编辑（PS／画布）+ 重绘** | 结构锁死；这一层之后不再动 |
| 3 | **放大 + 轻度整图重绘** | 放大到 **`1200×1800` 挡位** → **整图 denoise 0.3** 丰富细节 | 细节够看；画面不糊、不漂 |
| 4 | **模型分流**（按需要） | ① 要 **IL 的质感** ⇒ 从图像**提取边线** → **IL img2img `denoise 0.8` + ControlNet（canny／softedge）**<br>② 有 **IL 专属角色 LoRA** ⇒ **IL img2img `denoise 0.6`** | 质感/LoRA 生效，人物没跑形 |
| 5 | **细节修正** | **PS + 局部重绘**：手指、脚趾、`vibrator`、rope 之类 | 逐处过（每处一张就够） |
| 6 | **放大交付 / 收尾** | 放大到发布尺寸 ⇒ 能结束就结束；**还要瞳孔这类更细的东西** ⇒ 走 **SmartCrop 工作流** | 尺寸、闸门、比例都过 |

## 三条纪律

0. **每一批图都要"嵌进对话"，不能只报路径。**
   agent 自己读图是 agent 在看，人看不到 —— 任何"请你判断/请你挑一张"的场合，
   都必须用一个**卡片**把图呈现出来：`dsh_show_media(file_path)`；
   要和旧版对照就用 **`compare_with`**（两张图一张"擦除对比卡"，可拖动中线），
   而不是自己拼一张缩略图或只给文件名。汇总多张才用 `make_grid.py` 出的联系表，
   并对联系表本身再调一次 `dsh_show_media`。
   报告任意一步的产物时，「路径 + 卡片」两样都要给。

1. **多张只属于第 1 步。** 抽卡是买"结构"的地方，一次 3–5 张；**进入编辑阶段后一般每次只跑一张** ——
   小 denoise 的样本间差别本来就小（实测同一底图 ×4 种子做区域重绘，四张几乎无可辨差异），
   继续抽的边缘收益极低。
   **例外**：重绘强度 **> 0.6**（尤其第 4 步换模型转 IL）时，输出方差重新变大 ⇒ **可以多抽几张**。
2. **"放大"要发生不止一次，因为细节的尺度不同。** 手指、脚趾、瞳孔这种小物件，
   **在它没有足够像素时是不可能画好的** —— 所以是"小尺寸抽结构 → 中间尺寸补细节 → 交付尺寸收尾"，
   而不是"一次放大到底"。每一次放大都对应"接下来要处理的那一层细节"的尺度。
   （同理，`references/local_repaint_bigcanvas.md`：denoise 能改动的宽度是**像素量**，随画布缩放。）
3. **denoise 决定"读"还是"重写"，不是"改多少"。** 蒙版内每一次都是整体重绘：

   | denoise | 能做的事 |
   |---|---|
   | 0.2–0.4 | 材质、线稿、小物件细节 |
   | **0.5–0.6** | 比例、表情、换引擎（IL img2img + 角色 LoRA） |
   | **0.8–0.9** | 结构/拓扑重写（**绳"连到床框"这种拓扑 0.4~0.75 出不来，0.9 才出来**） |
   | 1.0 | 重抽 |

   换材质/颜色靠**提示词**，不靠加 denoise。

## 第 1 步：抽卡定底图（Anima / 小尺寸）

- **引擎**：Anima（qwen-image）默认。**LoRA 绝不跨基底**：`networks.lora_anima` 只能挂 Anima，
  `lora_te1_*`（SDXL/IL）只能挂 IL —— 挂错不是"效果差"，是出坏图。
- **尺寸 `800×1200` 挡位**（0.96 MP ≈ 训练分辨率附近）。这一档**只是抽结构**，
  脸/手指在这个尺度上必然偏软，**不要在这一步评判细节**。
  画布按取景选（`references/prompt_cheatsheet.md` 的尺寸表），但要守住"人物矩形 ≥ `700×1200`"那条 ——
  它是"脸会不会走形"的门槛，见 `SKILL.md` §Subject pixel area。
- **3–5 张一起出**，只挑结构对的。**结构不对就继续抽，不要在错的画面上打磨**
  （`references/planning_and_decomposition.md` §3 宏观/微观）。
- **多人**：画布要**宽**（双人 `1216×832`；竖构图会把两人叠起来）；提示词里每个角色一块
  （外观词抄各自 LoRA 的 `trainedWords`），负面加 `1boy, male, muscular`。
  **多人图默认 Anima**（IL 双人易"两人做同一件事"或把一方画成男性）。
- 提示词写法：Anima 用"整场景一句 + 要素短语"，风格块只写一次（`references/prompt_writing.md`）。

## 第 2 步：大尺度结构性修正（人工 + 重绘）

**只有结构性问题才在这一步处理**：胳膊/腿的位置、身体朝向、谁在哪儿、遮挡关系。

- **人工改稿当底图**：手改稿本身就是画布 —— **照它重绘，别另存新底**；
  改动内容**必须写进提示词**（改了短发就写 `short hair`），否则 0.5~0.6 会把 LoRA 的默认外观拉回来。
- 重绘用 **`SetLatentNoiseMask` + `denoise 0.5~0.6`**（改位置/朝向属于"比例与结构"档）。
- **这一步的输出就是后面所有步骤的底**，所以：先量一下改动性质（`|Lap|` 边缘能量、色数）再定 denoise，
  并**把未经回贴的原始输出也留档**（`*_raw.png`）。
- **多人分区**：mask 只框当前这个人；**只挂当前这个人的 LoRA**（同时挂两人的会在 latent 里互相拉扯）；
  提示词写整场景但把对方降级成 `another girl sitting beside her`（写全对方外观会把特征污染过来）。
  **不能跨基底挂 LoRA**（第二个角色只有 SDXL 版时，要么整条换基底，要么她只用文字描述并在记录里注明妥协）。
  **同一引擎的 pass 排在一起跑**（6 GB 卡上换引擎＝卸载+载入，顺序直接决定代价）。
- **换引擎必须按 mask 回贴**：IL 的 VAE 会把整幅图重编码（实测 mask 外 mean 8.08，肉眼可见），
  回贴后 mask 外 0 像素变化。

### 重绘的提示词纪律 —— 判据是"**画布上还剩多少上下文**"

| 重绘方式 | 画布上有什么 | 提示词怎么写 |
|---|---|---|
| **全画布 mask 型**（`SetLatentNoiseMask`，整幅在画布上） | 整个场景 | **写整个场景**；其他角色**简化成占位词**（写全 = 让模型按你的文字重画她） |
| **裁切 / crop 型**（SmartCrop、裁块重绘） | **只剩裁片** | **只写裁片里看得见的东西** —— 写公园/腿/角色名而裁片里只有两只鞋，等于让模型画它**看不见**的东西 |

**收窄 mask 就要同步收窄提示词。** 细节与实测：`references/local_repaint_bigcanvas.md`
（§多人图里的分区重绘、§The prompt must describe only what is inside the crop）。

## 第 3 步：放大到 `1200×1800` + 整图 0.3

- **先放大再补细节**：在 `800×1200` 上画不好的东西（绳路、织物、发丝），到这一档才有足够像素。
  用 `4x-AnimeSharp → Lanczos` 到目标尺寸（`references/upscaling.md`）。
- **整图 img2img `denoise 0.3`**（无蒙版）＝"轻度重绘丰富细节"：结构不动，材质与线稿变干净。
- ⚠ **整图路线的代价**：整张都要过一遍 VAE 编解码 + 采样 ⇒ **蒙版外不是逐位不变**
  （实测：2000² 上 0.7% 像素轻微变化、最大差 78）。要求"蒙版外 0 改动"就必须走 **PIL 贴回**那条路
  （`references/local_repaint_bigcanvas.md` §The no-custom-node route）。
- ⚠ **全图重绘在画布过大时会掉有效分辨率**（2000² 上 0.6 重绘会把脚趾重新糊掉）——
  尺寸和"这一趟要改什么"必须匹配，见纪律 2。

## 第 4 步：模型分流（要用 IL 的时候）

按需求二选一，**两者都是 IL img2img**：

| 需求 | 做法 | denoise |
|---|---|---|
| 要 **IL 的质感**（平涂感弱、笔触/光照不同） | 从当前图**提取边线**（`canny` / `softedge`）→ **IL img2img + ControlNet** | **0.8** |
| 有 **IL 专属角色 LoRA**（该角色没有 Anima 版） | **IL img2img**，挂该 LoRA | **0.6** |

- 0.8 已经属于"重写"档 ⇒ **这一趟可以多抽几张**（纪律 1 的例外）。
- 边线路线用 ControlNet 锁构图，正是为了让 0.8 不乱跑；控制图要匹配采样画布
  （`references/blender_control_pipeline.md`）。
- 换引擎 = 换 VAE ⇒ 输出**按 mask/整图回贴**，别直接拿 IL 的整幅输出覆盖底稿。
- IL 侧参数：`dpmpp_2m` / `karras` 28 步 `cfg 6.5`；Anima 侧 `euler` / `simple` 30 步 `cfg 8`。

## 第 5 步：细节修正（PS + 局部重绘）

手指、脚趾、`vibrator` 之类的小道具、绳路 —— **一处一趟，每趟一张**：

1. **人（PS 或画布）**：改稿或涂出"要改的范围"。这是全流程里**最省算力的一步**，
   能让人定位就让人定位（`references/human_in_the_loop.md`）。
2. **agent 自定位的替代**：站姿/跪姿可用本机 OpenPose 节点出部位框当蒙版初框
   （`references/local_repaint_bigcanvas.md` §自动定位部位）；**四肢着地、吊缚这类极端姿势会掉关节**，
   那时用 `SAM3_Detect` 或请人粗涂一笔。
3. **强度**：材质/小物件 `0.2~0.4`；想改结构就回第 2 步。
4. **验收**：`diff_report.py A B --mask M` 看"蒙版外"这一列；要 0 就走 PIL 贴回。

## 第 6 步：放大交付 / 收尾

- **放大到发布尺寸**（本机惯例：`4x-AnimeSharp → Lanczos 到宽 2000`，高取偶），跑 WD14 闸门，
  多张之间**比例不必强求统一**（横/竖/方各随其源即可）。
- 还要更细的东西（**瞳孔、睫毛、首饰**）⇒ **SmartCrop 工作流**
  （`SmartImageCrop → SetLatentNoiseMask → SmartImageStitcher`；模板与坑见
  `references/smartcrop_repaint_workflow.json` 与 `SKILL.md`）。
  该路线**蒙版外有 0.2~0.5% 漂移**（实测：0.2862%），代价是接缝比手写裁切更自然。
- 到这一步还没解决 ⇒ 说明问题在第 1 步（结构），**回抽卡**，不要在第 6 步硬修。

## 不适用本流程的三种活（各有专文）

- **漫画页 / 多格拼版**：`references/comic_page_layout.md`（逐格出图 → 拼版 → 气泡）。
- **云端编辑**（本地结构弱项：图内文字、摆位、换背景）：`references/cloud_edit_and_merge.md`
  —— 云端**不能做 R-18 编辑**（输入侧审核 400）。
- **要精确姿势/相机**：Blender 控制图路线 `references/blender_control_pipeline.md`
  —— 此时第 1 步的"抽卡"被"搭场景"替代。
